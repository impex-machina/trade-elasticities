## Reading the comparison — v0.4.1 → v0.5.0 (BW fn-14 calendar lag)

**Prediction recorded before adjudication.** Stage 1 (HLIML wrapper) contains no
BW weights, so σ was predicted bit-identical: confirmed — 280,649 rows identical
on all shared columns (the FILE hash changes via patch 0013's canonical save;
the data does not). Stages 2a/2b reweight only; the HS4 gap census
(`analysis/hs4_bw_gap_census.R`, folded into the same EC2 run) found 52.8% of
bilateral series carry internal holes and 7.15M rows (9.1%) received a stale
x_{t-2+} under the legacy positional shift, touching 91.0% of cells (median 20
stale rows per affected cell). Because bw_weight() maps NA → 1 against typical
fn-14 weights of order 10^4–10^5, calendar mode is effectively a ~9% sample
restriction spread thinly across nearly all cells — the prediction was broad,
small movement with near-invariant marginals.

**Observed.** 95.2% of 6.82M matched (importer, exporter, HS4) estimates moved,
but the median |Δγ| is 0.0024 (p75 0.025, p90 0.16, p95 0.38, p99 1.46) against
a γ median of 0.68; membership churn 8,586 out / 8,085 in (0.12%), zero tier
changes. Marginals: γ median 0.679→0.678, p95 1.949→1.940, share γ>1
23.6%→23.4%, opt_tariff 0.713→0.709, tier and SE-status compositions identical
to the tenth of a point; SE medians up 1–2% (γ_se 0.604→0.611), consistent with
fewer effective observations per cell.

**Mechanism signature.** By tier (p50 / p99 |Δγ|): Tier 0 reference exporters
0.047 / 4.94 — the reference exporter is identified off the cell's export-side
moments and takes the full reweight; Tier 1 0.0055 / 1.60; Tier 2 0.002 / 0.86;
Tier 3 0.0004 / 0.034 — regional assignments move only through the Stage-2a
prior. Dose-response against the census is monotone across quintiles of
stale-row count (cell-median |Δγ| 0.00064→0.00353; cell-max 0.014→0.68; share of
cells moved 89.8%→100%; Spearman 0.22 on the median, 0.45 on the max). Cells
with few panel-level stale rows still move because cell-level filtering
(reference joins, moment-NA drops) adds fallback rows the panel census cannot
see — the census is a lower bound by construction.

**Adjudication: SHIP.** All four gates cleared (σ bit-identical; movement located
where the census places the stale lags; marginals modest and explicable;
churn small). The weight-1 fallback for post-hole rows is now empirically
established as marginal-invariant at HS4; whether a nearest-prior-year lag or a
non-unit fallback would be preferable remains an open design question, noted,
not acted on. Legacy mode remains a first-class flag (`--bw-lag legacy`) and
reproduces v0.4.1 bit-for-bit.
